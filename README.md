# Hola Mundo en Java

Este es un programa básico escrito en Java que imprime el clásico mensaje "Hola Mundo" en la consola. Es el punto de partida estándar para verificar que tu entorno de desarrollo está configurado correctamente.

## Requisitos

Para compilar y ejecutar este código, necesitas tener instalado:
* **Java Development Kit (JDK)** (versión 8 o superior).

Puedes verificar si ya lo tienes instalado ejecutando en tu terminal o línea de comandos:
```bash
java -version
